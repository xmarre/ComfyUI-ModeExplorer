# Local response measurement and steering

ModeExplorer Response uses native Krea 2 evaluations inside the existing ModeExplorer diffusion wrapper. The tests use a small Krea 2 transformer with random weights. Full-checkpoint response stability, image quality, CUDA backend behavior and memory cost require measurement on production checkpoints.

## Posterior identity and native coordinates

Let the forward corruption be $z_t=\alpha_t x_0+\varepsilon_t$, with $\varepsilon_t$ Gaussian of covariance $\Sigma_t$, independent of $x_0$. For positive $\alpha_t$ and nonsingular $\Sigma_t$, expanding the Gaussian likelihood at $z+\delta$ multiplies the posterior by a factor proportional to $\exp(x_0^\top \alpha_t\Sigma_t^{-1}\delta)$. An exponential tilt $\lambda$ is therefore realized by $\delta=\Sigma_t\lambda/\alpha_t$. For the exact posterior mean $D$,

$$
J_D(z_t)=\alpha_t\,\operatorname{Cov}(x_0\mid z_t)\Sigma_t^{-1}.
$$

In isotropic coordinates $J_D$ is symmetric and positive semidefinite. The empirical probe reports symmetry and negative spectral mass of a small projection. Model approximation, guidance, distillation, off-axis rounding, finite perturbation size, and repeat noise can all affect those measurements. A low symmetry error over this subspace is one local observation. Semantic uncertainty and image quality require independent evaluation.

The native ComfyUI Krea 2 model uses FLUX sampling with CONST. The model keeps the solver-coordinate input and casts it to the inference dtype. The timestep presented to Krea 2 is the actual flow sigma. Noise scaling uses $z_t=(1-t)x_0+t k\epsilon$ for isotropic unit Gaussian $\epsilon$ and configured scalar noise scale $k$. The effective tilt per unit input displacement is $(1-t)/(t k)^2$. At pure noise the formula for realizing a nonzero posterior tilt is singular. Probing a bounded actual input shift is still possible there. Export a separate endpoint run with an inclusive maximum sigma of 1.

The runtime observes the cast DiT input $x$. Predicted-clean diagnostics use $D(x,t)=x-t v(x,t)$, in FP32. For a shifted input $x+\delta$, the diagnostic includes the realized $\delta$ in the clean estimate. To deliver a clean correction to the original native call, the runtime uses $v_{\rm new}=(x-D_{\rm new})/t$ and casts back to the native output dtype. ComfyUI then applies its clean conversion at the original solver state. Exports contain conditional estimates in the DiT input coordinates converted to the VAE latent format. They can differ from the sampler’s CFG-combined prediction computed with its pre-cast latent.

[Posterior Matching Distillation](https://arxiv.org/abs/2611.26629) proves Tilt=Shift and posterior identification. Appendix B states the covariance identity for the derivative of the exact conditional-mean denoiser. ModeExplorer estimates an empirical projected derivative. Its centered unnormalized residual equals the normalized residual times $\exp(K_p(\lambda)-\lambda^\top T_\lambda)$. The zero sets agree and the weighted squared objectives differ away from those zeros. For Appendix C’s four-student cross-fit, deleting one draw from a pair leaves a singleton whose normalized residual is the sample residual. FLUX training omits direct PMD supervision at the pure-noise evaluation. Appendix D finds different diversity and fidelity behavior across spatial and radius choices. Appendix E separates stochastic posterior matching for diversity from the adversarial term for quality. ModeExplorer applies bounded local probing and steering at inference using the pretrained Krea 2 architecture.

## Phase I · Local Latent Response Probing

At an eligible actual positive dispatch, the node evaluates both signs of each direction with the original timestep and conditioning and preserves the live sampler output. It keeps the positive/negative packing and replaces only the positive input row in auxiliary calls. The baseline can be reused when the live forward is actual and unedited at the measured state. The default uses two directions, a repeated baseline and a half-amplitude repeat for the first direction that can be measured. That costs seven forwards with a reusable baseline. With packed CFG it evaluates two rows per call, for fourteen auxiliary DiT rows. Split conditioning dispatches use the positive row.

| Basis | Construction |
| --- | --- |
| Gaussian | Independent native latent coefficients from a private CPU generator. |
| Coarse | Rectangular piecewise-constant cells. Partial edge cells occupy their actual area. |
| Bilinear | A Gaussian field interpolated over the full rectangular image. |
| DCT | A random low-frequency cosine expansion along each image axis. |
| Reference | A deterministic independent unit-noise field minus the current cast latent, followed by normalization. Feature replay independently uses the shadow reference bank. |

Directions are orthonormalized in the physical latent grid with reorthogonalization and rank rejection. RMS displacement is L2 divided by the square root of the number of latent entries. The trace records requested and realized norms, asymmetry, off-axis error and dtype. It uses unequal-step three-point differences with the realized projected steps. Large off-axis rounding, unresolved steps and nonfinite outputs cause rejection. Set the input RMS trust limit independently of the requested displacement, and use the latent cell control to restrict a direction to one row-major cell before normalization. Both RMS controls use the full latent. For a cell occupying one sixteenth of it, the RMS within that cell is four times the full-latent RMS. Repeat error and half-amplitude sensitivity help distinguish numerical noise from a resolved response. Curvature measures finite-amplitude behavior and is especially sensitive to off-axis rounding and cancellation. With calibration enabled, the default Auto precision mode tests the representability of each full and half-amplitude pair before calling the model. For BF16 or FP16 it chooses one amplitude per state, taking the smallest tested amplitude that resolves the most basis directions under the 10 percent off-axis and input RMS trust limits. Every column of the projected response uses that amplitude. If only a subset resolves, unresolved directions are excluded. If none resolves, the configured amplitude remains available for rounding-limited diagnostics and active steering requires a valid calibration. The search is bounded by four times the configured displacement and spends no model forwards. The trace records the configured and common displacement, precision-eligible directions, and which direction indices entered the projected matrix. Use Fixed precision to retain the requested measurement amplitude for comparisons. Candidate application still uses the configured displacement.

The trace distinguishes rounding-limited geometry from a measured half-amplitude change above the configured stability limit. It also reports the change in effective input direction for a measured pair. These fields help interpret small symmetry errors and negative spectral mass. Active response-based steering requires a stable measured calibration for the first usable direction when calibration is enabled.

The node selects by actual sigma or the zero-based ordinal of an actual positive dispatch. The sigma-window mode selects at most two distinct levels. Exact ordinal selection can address separate solver evaluations at the same sigma. Forecasts never qualify as measurements. The node accepts an initial unmasked full-denoise image or a tagged planner pass. Tagged refinement passes bypass the experiment.

## Phase II · Projected and feature response

For input basis $B$, each central difference gives an estimate of $J_DB_i$. The node reports $H=B^\top J_DB$, its original symmetry error, singular values, eigenvalues of its symmetric part, directional quadratic forms, negative eigenvalue mass as a fraction of absolute eigenvalue mass, full-output response gains, and entropy-based effective rank.

The feature replay runs the native transformer at the same state using the pre-gate, pre-output-projection attention hook. It measures velocity and predicted-clean displacement. Joint probing projects that output displacement onto an orthonormal basis of measured **output** responses. It reports cosines, projection coefficients and residual energy. Optional later-block capture measures before/after differences in small pooled attention summaries and costs one extra baseline forward. This measures within-forward propagation. Use matched trajectory runs to measure propagation across denoising steps.

A regular feature replay selects one block and one grid. Component experiments use native query-output head count and width from the loaded block, plus zero-based row-major cells in the actual pooled grid. The raw component modes keep the original coefficients. The matched variants rescale the retained component to the full proposal’s token-weighted L2 before native rounding. The trace reports both proposal and realized edit magnitudes. To measure head-wise or block-wise amplification, sweep the same seed, frozen state and magnitude over those selections. The edit affects only positive generated tokens.

The native/sham/repel/reverse/channel-sign panel isolates the original Early Feature Micro-Steering intervention. For a single cosine reference, the initial direction is $c u-v$, where unit feature vectors $u$ and $v$ have cosine $c$. The inner product with $u$ is zero. The bounded edit then applies centering, the spatial norm bound, and the strength envelope $s(1-0.85f)$ before saturation and optional adaptive scaling. The 0.025/0.70 setting gives a nominal envelope of 0.010125. Calibrate realized coefficient and clean displacement from the trace. The new replay adds a random direction projected into the centered live feature tangent space, and spatially matched random coefficients with shared per-cell proposal norms. Tangent matching, proposal magnitude matching and downstream displacement matching define distinct experiments. Use the realized magnitude fields when constructing downstream-norm-matched panels.

## Phases III and IV · Posterior-Sensitivity-Guided Steering and acceptance

| Mode | Candidate construction |
| --- | --- |
| Latent steer | Both signs of the dominant projected right singular vector or the top eigenvector of the symmetric part. Measure the candidate at a shifted input and move its clean prediction to the original state. |
| Feature steer | Native measured feature replay responses. Repel and reverse are paired by default. Disable the paired feature control to test one sign. Other feature controls form single-candidate experiments. Response alignment ranks feature candidates by the fraction of clean displacement energy captured by the measured latent-output subspace. |

Feature steering can compare up to four verified block/head sites on the same frozen input. Enter block:head pairs in the feature sites field and select the response-alignment policy to rank them by measured subspace overlap. The forward budget must cover the complete set. For example, four sites with two references and one arm per site require eight auxiliary forwards for cold reference and arm evaluation. Set feature projection to response subspace to use the projection of each feature-induced clean displacement as the actual candidate correction. This projection operates in clean-output coordinates.

The clean trust region and repeated-baseline floor bound eligible candidates. The trace lists the baseline alongside the proposals and records the selected arm. The gain scales each candidate’s clean displacement and native-output rounding precedes active scoring. The minimum-change and response-RMS policies rank candidates by their smallest and largest displacements, respectively. Response alignment ranks feature candidates by measured output-subspace overlap. These modes measure numerical quantities. Set a candidate target RMS to compare arms at a common downstream magnitude. The target must be reachable within the gain envelope. Native-output rounding must achieve it within 10 percent.

The external policy requires a local custom node to output a callable on the MODEEXPLORER_LOCAL_SCORER socket. The callable receives a detached FP32 conditional clean latent in ComfyUI VAE format on the model device, along with a copy of the trace metadata. The latent can be passed directly to the matching VAE. Return a finite real scalar for quality or a dictionary with quality and optional conditioning and fidelity scores. Higher values indicate improvement for each metric. When enabled, the conditioning and fidelity gates require scores at least as high as the baseline. Quality must strictly improve for the same state. Invalid or absent required scores retain the baseline. Exact ties between eligible candidates retain the first candidate. A scorer should be deterministic, read-only, local and use its own RNG if needed. Quality validation belongs to the scorer and the held-out comparison. Calibrate count and relative position with labeled cases and supported local detector classes as in GenEval. Use specific visual questions and mutually exclusive alternatives for prompt adherence as in TIFA. Use independent human criteria for hand/object relations, anatomy, identity and meaningful detail when automatic measures lack agreement on the exact predicted-clean inputs. [GenEval](https://arxiv.org/abs/2310.11513), [TIFA](https://arxiv.org/abs/2303.11897) The export-only policy evaluates candidates for offline human review while leaving the generation unchanged.

Steering uses a native MODEL branch with CFG 1, native CFG callbacks, and production ModeExplorer guidance and initialization disabled. This keeps the configured clean trust bound at the sampler-facing conditional prediction. When Spectrum is installed, the steering node scopes Spectrum’s existing all-actual contract to that sampling invocation. This covers all solver steps on that invocation because Spectrum’s captured internal features cannot encode a post-DiT velocity correction. Existing Guarded and Full routing continues in ordinary feature and diagnostic runs. A diagnostic can explicitly request the all-actual route to test causal comparisons. Auxiliaries use isolated Spectrum and Sol scopes. The solver, sigma schedule, initial latent and solver RNG retain their normal operation.

PAG perturbs selected attention maps toward an identity operator. HeadHunter selects heads against an external objective and SoftPAG interpolates attention maps. ModeExplorer measures the output of selected heads at the post-aggregation hook. SAE feature interventions offer complementary ways to study time-dependent concepts. Idealized diffusion speciation motivates early-window experiments. [PAG](https://arxiv.org/abs/2403.17377), [HeadHunter and SoftPAG](https://arxiv.org/abs/2506.10978), [Interpretable Concepts](https://arxiv.org/abs/2504.15473), [Dynamical Regimes](https://doi.org/10.1038/s41467-024-54281-3)

## Resources and exports

Each central direction uses two sequential DiT forwards. Calibration adds a repeat and up to one half-scale pair. Frozen feature replay uses one to three shadow references per state and one forward per arm. Cold replay at a later sigma runs each positive-only shadow first at the first eligible actual sigma. It reconstructs the first-estimate clean term and continues the shadow to the measured sigma. Both shadow forwards are shared by all cold block/head sites for that reference. The later forward captures pooled features for all requested blocks. Each intervention arm still costs its own forward. A live first-estimate run with matching block, grid, reference count and start sigma reuses the live pooled shadow features. The Reference min sigma control sets the eligibility floor independently of the response window. It inherits the model’s feature floor by default, which is 0.82 on a native branch. Reference start sigma pins the start to a specific observed actual evaluation. Set it from the live arm’s feature_reference_initial_sigma when matching that arm. If the current schedule never reached the requested start before the probe, the feature arm reports reference_start_not_observed. A frozen export can supply the recorded start and Sol evaluation ordinal, including when the replay schedule omits that earlier evaluation. A different explicit start uses the current run’s observations. The trace records the chosen start, its source, and feature_reference_calls. Replacing an edited baseline or enabling downstream capture adds a baseline forward. The response budget includes candidate and shadow calls. Research workspace checks include separate attention clone and pooled-capture allowances. The limit covers research tensor allocations and excludes the ordinary native model forward and backend allocator overhead. A large planner may require a higher feature-replay workspace setting. Tagged refinement never allocates probe workspace.

The MODEEXPLORER_TRACE response section uses schema 1. It records completion and rejection, condition and input fingerprints, realized perturbations, flow noise scale, auxiliary DiT calls and processed rows, and selected candidates. Track the companion Spectrum traces to compare realized routes. Missing values are JSON null, and the trace distinguishes skipped and rejected measurements from numeric zeros.

Export is opt-in. The run writes up to 64 MiB of tensors under the ComfyUI output directory in modeexplorer_response. It includes a JSON manifest and Safetensors predictions. Use **ModeExplorer Load Response (Krea 2)** with the export ID and a tensor name such as baseline_clean or feature_repel_clean. Connect its LATENT to the normal Krea 2 VAE Decode. Preserve these files locally when prompts or generations are private.
