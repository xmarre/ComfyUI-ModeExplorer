# Research and implementation notes

The source audit used [ComfyUI c8abeb00ad2736b649ca2fceb8395e25072c7ea3](https://github.com/Comfy-Org/ComfyUI/tree/c8abeb00ad2736b649ca2fceb8395e25072c7ea3).

## Evidence and limits

Both checkpoints resolve to Krea2 / SingleStreamDiT in ComfyUI. Native CPU noise is seeded per requested seed (or indexed batch noise). Tests verify that distinct seeds produce distinct tensors under the standard path. Workflow wiring, reused seeds or indices, disabled noise, and rounding or patch effects remain possible in a particular graph. The public [Krea technical report](https://www.krea.ai/blog/krea-2-technical-report) and [inference repository](https://github.com/krea-ai/krea-2) identify Turbo's few-step and guidance distillation, and recommend no CFG for Turbo and full CFG for Raw. This makes distillation and CFG separate hypotheses. Fewer/larger solver steps, tightly specified prompts, LoRA weights, and planner/refiner settings also need separate controls. Source inspection cannot establish that any checkpoint collapses, locate the convergence time, or assign causality.

The [SDA LoRA](https://huggingface.co/F16/krea2-turbo-sda) uses a Raw teacher and a learned alignment objective on paired clean predictions. Its fixed-panel numbers evaluate that LoRA only. [Krea Explorations](https://github.com/fblissjr/krea-explorations) documents native/modular sampling, Raw with a Turbo adapter, and a two-resolution pass. [Krea Seed Variance Enhancer](https://github.com/harukimix/KreaSeedVarianceEnhancer) changes conditioning by adding seed-dependent noise to text embeddings and serves as an independent baseline.

## Paper mechanisms

| Source | Mechanism and engineering implication |
| --- | --- |
| [FSG](https://arxiv.org/abs/2606.27371), §§3–4, Algorithm 1 and [code](https://github.com/PradhaanSBhat/Dont-Settle-at-the-Mode/blob/main/src/dont_settle_at_the_mode/utils/fsg.py) | Minimizes log-mean-exp of pairwise cosine similarity in early internal image features, then runs the same block again and blends the two features. The paper's early window and second block motivate the Krea 2 settings. The hook, gradient scale and fidelity constraint require independent validation. |
| [DetNO](https://arxiv.org/abs/2610.22267), §4, Algorithm 1 and appendix, [code](https://github.com/mobled37/DetNO) | Minimizes negative log determinant of an RBF Gram on pooled normalized predicted-clean latents, with a spatial x0 anchor. The SD3 implementation stops gradients through velocity, leaving the identity path from xt to x0. A ridge and bandwidth floor are essential for near duplicates. |
| [DivIn](https://arxiv.org/abs/2606.02453), §4 and Algorithm 1, [code](https://github.com/South7X/divin) | Tilts a Gaussian prior by the negative conditional–unconditional clean-prediction gap, then takes Langevin steps including the Gaussian score and stochastic term. It requires a meaningful unconditional prediction and a derivative through the model. Neither is assumed for Turbo. |
| [Collapse recovery](https://arxiv.org/abs/2601.00090), §3, [code](https://github.com/anneharrington/divgen) | Optimizes initial noise through the complete frozen denoising map using image-space diversity and quality rewards with stop/revert thresholds. Sequential optimization depends on past outputs. Its pink-noise option modifies a spectral prior. Neither full trajectory gradients nor mutable output history meet the default runtime goal. |
| [DiverseFlow](https://arxiv.org/abs/2504.07894), §§4–5 | Couples ODE particles using log det(L) minus log det(L+I), applied to predicted endpoints. Source-radius quality supplies a separate constraint. This supports using predicted endpoints and collective volume, but its coupled ODE changes and backward passes are outside the native sampler integration. |

A measure-preserving transform of a standard Gaussian cannot restore population diversity under a fixed deterministic generator. Feature guidance changes the velocity operator. Initialization changes the input law through a model-dependent edit with an explicit trust region.

## Native Krea 2 integration

Krea's [sampler](https://github.com/krea-ai/krea-2/blob/main/sampling.py) draws a Gaussian per seed on the model device, predicts velocity, and uses Euler from flow time 1 to 0. ComfyUI's noise tensor is drawn on CPU, then moved to the model device. The two RNG paths need separate baselines. Krea's standalone guidance is v_cond + g(v_cond − v_uncond). ComfyUI expresses it as v_uncond + cfg(v_cond − v_uncond), so the equivalent coefficient is cfg = 1 + g. Their scheduler implementations and precision can still differ.

In the inspected native backend Krea 2 uses `ModelType.FLUX`, `ModelSamplingFlux`, and `CONST`. The transformer input is xt, its output is flow velocity, and ComfyUI's clean estimate is x̂0 = xt − σvθ. Noise at the first sigma is `σ·noise_scale·noise + (1−σ)·latent`. The standard empty image is converted to a Wan21 latent with one temporal frame. Native KSampler, KSamplerAdvanced, and modular sampling converge at CFGGuider → KSAMPLER → positive/negative condition batches → Krea2 → SingleStreamDiT. ComfyUI may dispatch CFG branches together or separately.

The Krea 2 source exposes no block-output replacement in this loop. Its `attn1_output_patch` runs on the second block's actual attention features before gated output projection and residual addition. The extension works at that interception point with the original model and LoRA weights. Generated image tokens lie after text and before reference tokens. The hook verifies the image region using the padded latent patch grid and the model's reported reference lengths. Downstream blocks can exchange information normally. The extension changes only the positive generated-image attention coefficients at the hook.

## Feature adaptations

Let P be disjoint spatial averaging over at most 4×4 cells and C subtract each channel's coarse spatial mean. For a cohort of same-condition responses h, set uᵢ = normalize(CPhᵢ). Cosine mode minimizes log-mean-exp of uᵢ·uⱼ / 0.5 over eligible off-diagonal pairs. Volume mode minimizes −log det(K + 0.001I) with an RBF bandwidth of 0.55 in unit-vector space. Ineligible, off-diagonal Gram entries are zero. Equality comparisons partition the Gram into independent positive-semidefinite blocks. With two members, the determinant is monotonic in their cosine distance, so the volume variant chiefly changes gradient weighting. Three or more equivalent batch members allow independent higher-order volume effects.

The update descends the loss through normalization and centering analytically. The row-wise gradient of the normalized representation is projected onto the tangent plane of the unit sphere. The centered coarse correction uses one scale per sample to bound each cell relative to its native attention norm. Broadcasting a common offset within each cell preserves within-cell detail and the coarse-grid mean up to native rounding. A separate redundancy gate ramps strength from the user threshold to one, and the absolute sigma window controls timing. This trust region takes the place of FSG's same-block replay. The FSG reference optimizes the complete feature tensor with AdamW, includes self-pairs in the average, and replaces and replays the selected block. Both ModeExplorer feature modes use separate Krea-specific adaptations. Tests compare their gradient directions to independent autograd formulations, including multiple conditioning groups and rank-deficient inputs.

With one image, the sampler seed deterministically selects one of eight fixed Gaussian references. The reference receives the same positive prompt, image dimensions, reference latents and weights. The first reference is evaluated at the first eligible actual sigma σa. At later eligible sigma values its state follows the first prediction's Euler tangent, x_ref(σ) = σ·noise_ref + (1−σ/σa)·x̂0_ref. It is measured again at that sigma. The update moves the live feature only. This generates a real same-conditioning comparison with bounded work independent of previous generations. It provides no mathematical guarantee of increased final-image mode coverage.

## Initialization adaptation

At the actual first native sigma, compute the guider's x̂0 on the requested Gaussian sample and two fixed Gaussian references. For each output row, build a separate three-by-three RBF Gram on normalized pooled predictions. Use the reference distance to set bandwidth, with a floor and ceiling. Take a single descent direction for the live row using the analytic Gram derivative and true pooling adjoint. The stop-gradient assumption leaves d x̂0 / d noise = σ·noise_scale. This follows DetNO's surrogate derivative for flow models.

Project that direction onto the initial noise's tangent plane. Rotate on its original Gaussian radius with a maximum entrywise RMS displacement of 0.18 × strength. The edit changes the explored distribution through a model-dependent direction while preserving sample radius. The fourth guider call evaluates the actual candidate. Accept only when the real log-volume rises by more than 0.0001 and the full clean-latent relative RMS difference is at most 0.32 − 0.27 × fidelity. Otherwise use the original Gaussian sample. This trust-region proposal and verification rule is an independent DetNO adaptation. It works with one output and with heterogeneous batches because the reference predictions are row-local.
