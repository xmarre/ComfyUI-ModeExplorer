# ComfyUI-ModeExplorer v0.1.0

Initial public release for native ComfyUI Krea 2 Raw and Turbo.

## Production guidance

- Seven selectable modes: Original, Early Structural (B0/B1/B2), Amplified Structural (B5), Middle Refinement and Custom.
- The five depth presets apply only the first eligible actual feature proposal and disable adaptive similarity scaling. Original and Custom retain the adaptive control and existing feature settings.
- Sequential cosine and RBF-volume guidance with a bounded auxiliary reference budget; equally conditioned batch guidance uses no additional feature forwards. Optional initial-noise search has an independent forward budget and fidelity gate.
- Native attention dispatch, upstream weight LoRAs, and ordinary MODEL wiring are retained. Tagged Scale-Locked high-resolution passes bypass feature guidance.

## Research tools

- Response and Mechanistic nodes, projection-local guidance and isolation, response export loading, trajectory review and local research reports.
- Matched sham and directional controls, frozen-state replay, numerical provenance and terminal-certificate checks, blinded report packaging, and example workflows.

## Installation and compatibility

Install `comfyui-modeexplorer` through ComfyUI Manager, use ComfyUI Patcher with the repository, or extract the release ZIP into the custom_nodes directory and restart. Native Krea 2 support is required. No ModeExplorer PR overlay is needed.

Optional guarded Spectrum integration requires [Spectrum Krea 2 PR #6](https://github.com/xmarre/ComfyUI-Spectrum-Krea2/pull/6) until its compatibility changes are released; Scale-Locked integration requires stage tags. See the [README](https://github.com/xmarre/ComfyUI-ModeExplorer/blob/v0.1.0/README.md) and [examples](https://github.com/xmarre/ComfyUI-ModeExplorer/tree/v0.1.0/examples) for setup and matched comparisons.

The pinned CPU integration suites cover native sampling, companion routing, archive qualification, and workflow schemas. The structural findings document records case-specific evidence and negative results. Generalized image-quality improvement, full-checkpoint CUDA coverage, and population-level performance are not established. Research interventions and Full Spectrum remain experimental.
