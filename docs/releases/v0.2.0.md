# ComfyUI-ModeExplorer v0.2.0

Adds ReDiverse for native Krea 2. Existing nodes, modes, defaults and saved workflows are unchanged.

## New nodes

- **ModeExplorer ReDiverse (Krea 2)**: the released ReDiverse first-step adapter for Krea 2 Turbo, active only on the opening model evaluation through scoped forward hooks (no weight merging; upstream weight LoRAs stay active), and optional teacher-direction steering (ReDiverse-TF) at a block's residual stream. Composes with ModeExplorer feature guidance and Response on one MODEL path.
- **ModeExplorer ReDiverse Calibrate (Krea 2)** and **ModeExplorer ReDiverse Directions (Krea 2)**: per-prompt Krea 2 Raw direction estimation into validated safetensors archives with full provenance, and reloading.
- **ModeExplorer Activation Probe (Krea 2)**: exact bounded-memory total variance, participation ratio, concentration and spectra of block outputs across seeds, with teacher-subspace retained-variance, alignment and deficit/excess reports.
- Experimental temporal ReDiverse-FT schedules: windows of up to 16 distinct evaluation sigmas, delayed activation and built-in or custom per-slot strength profiles, with per-slot diagnostics. The default remains the one-evaluation reference recipe.
- **ModeExplorer Reference Sigmas (Krea 2)**: the reference Turbo and Raw FlowMatch Euler schedules.

## Integration

- Guarded Spectrum (with the ModeExplorer overlay) keeps the adapted evaluation actual and restarts forecast history after it; without the overlay contract the pass runs all-actual. Full Spectrum is rejected with ReDiverse.
- Tagged Scale-Locked high-resolution stages, partial denoise and masked latents bypass ReDiverse.
- Evaluator profiles for a reference panel (arms A–G) and a production panel (arms A–D and a route-matched sham), in-graph per-prompt calibration with recorded calibration cost, temporal FT screening panels, and six example workflows.

## Status

The adapter weights are not included; download them from the official gated release under the Krea 2 Community License. Scheduling, isolation and numerical contracts are covered by CPU integration tests on the native Krea 2 transformer. Behavior on real checkpoints, CUDA and INT8 ConvRot kernels, and all perceptual effects (diversity, anatomy, identity, adherence) are not yet established; upstream-reported diversity gains have not been reproduced. Experimental schedules and cohort steering are research arms. See the [ReDiverse guide](https://github.com/xmarre/ComfyUI-ModeExplorer/blob/v0.2.0/docs/rediverse.md).
