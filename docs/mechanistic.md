# Full-resolution mechanistic experiments

**ModeExplorer Mechanistic (Krea 2)** measures a bounded feature intervention at matched native diffusion inputs. Put it after any production ModeExplorer node and before Sol and Spectrum. It uses the Response wrapper slot, so use one research node per model branch. It leaves the sampler output untouched under the default `component=observe` and `treatment=export_only`. The existing ModeExplorer and ModeExplorer Response nodes keep their controls and defaults. Passive measurements follow Spectrum’s existing route unless you explicitly enable `all_actual`. Active treatment always forces the all-actual path.

## Native sites

| Selector | Tensor captured from the executed Krea 2 forward |
| --- | --- |
| `attention_pre`, `attention_post` | Native attention output at the intervention hook, immediately before and after native-dtype addition |
| `gate_logits` | Output of the attention `gate` linear module |
| `projection_input`, `projection_output` | Actual attention output times sigmoid gate, and the executed output projection result |
| `after_attention` | Residual stream entering the post-attention norm, after the block's modulated attention addition |
| `mlp_input`, `mlp_output` | Actual modulated input to the MLP and its immediate output |
| `after_mlp` | Block return after the modulated MLP residual addition |
| `final_projection` | Final native linear projection before image-token unpatching and cropping |
| `final_projection_unpatched` | The same final projection's packed channels rearranged and cropped using Krea's native output layout |
| `velocity`, `clean` | Cropped native velocity and FP32 clean estimate in diffusion coordinates |
| `sigmoid_gate`, `attention_contribution`, `mlp_contribution` | Unsupported. Exact standalone values require instrumentation inside native functional expressions |

Select zero-based `blocks` with ranges such as `5,8,12-14`. The independent `feature_block` selects the injection site. The final projection views, velocity, and clean use one global site key each. Requesting both projection views shares one CPU capture per arm. Internal spectra contain only the generated image tokens. Krea's native image slice and reference-token counts define these bounds. The patch grid includes the native padding on odd latent dimensions. Output latent spectra use the cropped grid. Frequency metadata accounts for the two-latent-pixel spacing of the patch grid.

The attention gate can shift energy into higher spatial frequencies between `attention_post` and `projection_input`. Compare these sites and the actual `projection_output` and `after_attention` results before attributing downstream changes to the gate or projection. A growing absolute RMS is compatible with a shrinking baseline-relative response. The residual stream's net band energy distinguishes amplification from changes that cancel existing content.

## Matched arms

| Arm | Conditioning | Intervention |
| --- | --- | --- |
| `D00` | C0, original positive | None |
| `D01` | C0 | Full bounded cosine proposal |
| `D0minus` | C0 | Exact negative of the same requested proposal |
| `D10` | C1, alternate positive | None |
| `D11` | C1 | C0's realized edit field in fixed mode, or independent C1 proposal in recomputed mode |

`signed` uses the first three arms. `conditioning_fixed` and `conditioning_recomputed` use the four factorial arms. `joint_fixed` and `joint_recomputed` add the negative arm. The fixed experiment reapplies C0's actual native-rounded difference in FP32 strips, rounds the resulting C1 activations to native dtype, and reports the discrepancy from C0. The recomputed experiment builds the proposal and reference continuation under C1 with the same noise slots. The signed experiment shares one requested proposal and records the actual opposing-edit mismatch. A comparison exceeding `symmetry_limit` is unqualified. Diagnostic spectra remain available and active even, odd, or fixed-interaction proposals require the relevant match.

Use a single global Krea 2 CONDITIONING entry per prompt. C1 accepts a different embedding sequence length and matching native reference latents and reference mode. Timed, regional, control and custom alternate metadata are outside this contract. Masks are recorded and the pinned Krea 2 forward does not consume them for these attention paths. Text-token activations are outside the FFT comparison, so no alignment is required. All auxiliary arms execute the positive row alone, even when the live CFG path packs conditional and unconditional rows. `sampler_velocity_baseline_rms_difference` reports comparison with the live positive output. At CFG greater than one the live sampler result retains its usual CFG behavior. Active treatment requires CFG 1 and bitwise parity with the live native baseline.

The latest observed actual sampler invocation determines the sigma, actual evaluation index and Sol ordinal. Set `states=3`, `evaluation=-1` and a window including the start to measure the first three eligible distinct actual sigmas. Use a native trajectory for a common baseline or attach Mechanistic after the existing weak guidance node for passive measurements along the guided trajectory. A component-treated trajectory can diverge after the first applied correction. For frozen matching, replay the local export at its exact sigma and matching conditioning, and check the native input hash.

## Reading the evidence

The paired metrics use orthonormal two-dimensional FFTs over each full-resolution channel. Band cutoffs use **cycles per latent pixel** at every site. Patch-grid FFT frequencies are divided by the patch size (2 for Krea 2). The common support is the square `|fx| ≤ 0.25, |fy| ≤ 0.25`. Inside that square, `dc` is isolated, `low` reaches the default radial cutoff of 0.0625, `mid` reaches 0.125, and `high` contains the rest, including representable diagonals. Frequencies outside the square are `sub_patch`, which has bins only at latent-grid sites. Check `frequency_bins` before interpreting a zero. Padding and cropping can give the two grids different discrete bin spacings. Compare band fractions or relative net change across sites and use absolute power within a site. Unpatching exposes the final projection's subpixel channels as spatial samples. Unstored negative-horizontal frequencies receive a factor of two, with DC and horizontal Nyquist columns counted once. For each band, with spectra `A` and `δ = FFT(edited − baseline)`, the displacement energy is `Σ|δ|²`. The cross-term is `2ΣRe(conj(A)δ)`. Their sum is the net change in absolute band energy. The trace also reports fractions of total energy and relative net change. Zero denominators are null. Spatial tile energy and the top 1%, 10% and 25% concentration use the sum of squared displacement over channels.

Site comparison keys include `positive`, `negative`, `odd`, `even`, `positive_vs_reflected_negative`, `conditioning_baseline`, `conditioning_edited`, `conditioning_interaction` and `feature_across_conditions`. Odd is `(D01 − D0minus)/2` and even is `(D01 + D0minus)/2 − D00`. Each signed site also reports the fraction of combined odd and even energy that is sign-even, overall and by band. For the factorial interaction the baseline field is `D10 − D00`, the edited field is `D11 − D01`, and their displacement is the interaction. Use `feature_across_conditions` to compare the two feature-induced correction fields directly. Use the energy maps with signed and conditioning contrasts to locate where the effect is concentrated.

`repeat_baseline` adds one exact matched forward and reports the clean repeatability floor. `amplitude_check` adds two signed half-proposal forwards, captures realized injection symmetry again, and compares native clean outputs. Half/full ratios near 0.5 for odd and 0.25 for even are consistent with linear and quadratic scaling at those amplitudes. Neither ratio establishes a derivative or determines the source of the effect. Use the exact captured dtypes, projection operator types, attention override, checkpoint provenance and measured repeatability. Kernel accumulation dtype is unobserved. A different backend with the same weights and input is a separate comparison from dequantization, the original unquantized weights, a fine-tune, or Raw/Turbo. Exact replay requires identical real-valued diffusion input and conditioning. Enable `match_cross_dtype` for a frozen replay across execution dtypes. The saved native latent must be exactly representable and the actual conditioning, mask and reference values must match by value. Use the provenance label that identifies the weight or execution change.

PMD Appendix B relates posterior moments and a conditional prediction derivative under its assumptions. ModeExplorer measures finite-amplitude responses of a learned denoiser and feature interventions are separate from that identity and from PMD training. The existing [Response node](response.md) still provides latent-direction probes. The Mechanistic clean components live in output space. Feeding one into a latent-input probe would require an explicit correspondence and a matched input-space measurement. Neither a small projection into a generic latent basis nor strong high-band displacement establishes semantic quality.

## Applying a component

Select `complete`, `odd`, `even`, `interaction`, or deterministic norm-matched `control`. `band` applies complementary low/mid/high/sub-patch masks to a native clean displacement in the same physical frequency coordinates. Smooth transitions optionally use cosine rolloffs. The low component contains DC. With `cell` enabled the filter is applied first, then the output is restricted to the selected cell, which can introduce boundary frequencies. A nonzero `candidate_target_rms` makes this a separate norm-matched candidate experiment and selects only when the native realized RMS is within the existing tolerance.

Use export-only to inspect `candidate_clean` before selecting `minimum_change` or supplying a local scorer through `external`. The scorer sees VAE-format predicted-clean latents. It can require both conditioning and fidelity scores at least as good as baseline. No correction applies at the zero-sigma endpoint or above the clean trust bound after velocity conversion and rounding. Active use is restricted to the planner or standalone native model with no preexisting feature intervention and with Spectrum in all-actual execution. A spectral component has no built-in quality score. Compare same-seed planner renders and score structure, conditional relation and local detail independently.

## Resource limits and exports

`auxiliary_budget` bounds DiT calls per sampler invocation. Every experiment forward adds one row. A diagnostic with output-only sites can reuse the live positive baseline when it is single-row, unedited and unfrozen. Internal measurements need one instrumented baseline, shared by all compatible arms. Each conditioning-specific shadow reference costs one forward at the measured state and one at the reference start when needed. A previously captured first estimate is reused within a sampler invocation when its native conditioning, reference conditions, sigma, backend, seed, dtype, shape and initial Sol ordinal match. Pooled proposals and shadow references are shared across requested sites.

`analysis_device=cuda` (default) keeps the native-dtype captures on the inference GPU. The node reports a skip if inference is on CPU or if the CUDA diagnostics cannot fit. Select `analysis_device=cpu` explicitly for host-side captures and analysis. The existing `capture_mib` and `chunk` widgets govern that fallback. The CUDA path uses a separate `capture_vram_mib` allowance (8,192 MiB by default, 10,240 MiB in the published GPU profiles) and `cuda_chunk` (32 channels by default). `memory_mb` still bounds other estimated GPU research tensors, such as the edit and reference buffers.

Preflight conservatively counts four bytes per captured activation and reserves extra space for spectral and output temporaries. It checks both the configured allowance and current CUDA headroom. The latter includes reclaimable PyTorch cache and is an estimate. The ordinary model forward, other work on the device, allocator fragmentation and library workspaces can affect actual peak use. `captured_bytes` records peak live capture tensors. Captures are released per site before the optional half-amplitude run. Diagnostic VRAM exhaustion reports a skip and retains the native prediction.

Each CUDA channel batch transforms the baseline and the required intervention/conditioning differences once, using cuFFT. All compatible comparisons reuse those spectra. The signed case transforms three fields per channel for five comparisons. Spatial and spectral reductions run on the analysis device. The FFTs and bulk reductions use FP32, with FP64 accumulation only for compact chunk summaries. Per-channel centering limits round-off leakage from DC into weak spatial frequencies. CUDA spectral analysis copies only compact statistics to the host. Fingerprinting and tensor export use host transfers separately.

The trace reports `analysis_device`, the channel batch size, `capture_preflight_bytes`, `capture_transfer_bytes`, and `timings_ms`. Timing keys include `auxiliary_dit` (excluding capture), `capture_copy` (same-device snapshots), `capture_transfer` (cross-device captures and edits), `spectral` (site spectra and spatial reductions), `edit_validation`, and `export`. CUDA timings use stream events and CPU timings use a monotonic wall clock. Export timing includes tensor transfer and serialization, with the trace also including the final manifest write.

With `export=true`, use `output/modeexplorer_response/<export_id>/manifest.json` and `predictions.safetensors`. Mechanistic tensor payloads have a 64 MiB allowance per measured state, bounded across the run by the requested states (up to 192 MiB for three). The original Response node has a 64 MiB per-run allowance. The signed observational profile saves seven FP32 fields per state. With about 15,700 image tokens and 16 latent channels this is about 26.8 MiB per state or 80.5 MiB across three. The base manifest retains schema 1 and its `mechanistic` section uses schema 2. The analyzer still reads schema 1 mechanistic exports, which used grid-cell units, and flags cross-version spectral comparisons. For old workflow settings, divide the cutoff numbers by two to retain the previous patch-grid band edges. Rerun for aligned latent-grid bands. `baseline_clean`, `D01_clean`, other named arm cleans, and candidate/applied cleans use the Comfy VAE latent format. `frozen_native_input` and `*_native_delta` remain in native diffusion coordinates. `ModeExplorer Load Response` decodes clean exports and supplies the matched two-step replay schedule. Full activations are staged for measurements and are never written as tensor dumps.

The offline analyzer reads one or two export directories. It includes layer profiles and site spectra, flags input and geometry mismatches, and can compute between-component cosine and normalized spatial-energy overlap from exported component fields.

```shell
python tools/analyze_mechanism.py PATH_TO_EXPORT --comparison conditioning_interaction
python tools/analyze_mechanism.py FIRST_EXPORT SECOND_EXPORT --comparison even --components even_native_delta even_native_delta
```

See [projection-level numerical isolation](projection.md) for packed output-projection replay, the affine reference and projection-component interventions.

## GPU sequence on the production planner

Use the [standalone workflow](../examples/mechanistic_signed.json) for a smoke run. Use the [profile settings](../tools/mechanistic_profiles.json) with the original production seed, sampler, scheduler, sigmas, geometry, checkpoint and attention stack. On the pinned Scale-Locked branch use `regeneration_mode=planner_final_upscale_only`, `handoff_diagnostics=off` and decode `lowres_planner`. This dispatches the same planner, then only latent enlargement, with zero target DiT evaluations. Choose the cheap interpolation option if the enlarged target is unused. Preserve the planner's original native-only Spectrum policy. Confirm the Scale-Locked log reports `target denoiser evaluations=0` and the ModeExplorer trace reports planner stage with zero forecasts. Do not use a capture of the enlarged latent as the original planner state.

1. Smoke-test the first eligible state with output-only capture and a matched repeat. Require completed clean metrics, a zero or measured repeat floor, a conforming signed edit, and a planner trace with `analysis_device=cuda:0` (or the inference GPU index) and `capture_transfer_bytes=0`. The first state with the reference start observed requires at most five auxiliary calls.
2. On one already informative seed, run the signed spectral profile for the first three actual states. Measure pre/post intervention, gated product, attention projection, residuals, unpatched final projection, and clean in the same run. Follow the common `high` band from `attention_post` to `projection_input` and `projection_output`, then to the output. For finer scales read `sub_patch` at `final_projection_unpatched` and `clean`. Check `signed_realized_edit`, `even_energy_fraction` at injection, and the amplitude check before interpreting downstream even energy. Verify `export_status=completed` at all three states.
3. Run the four-arm fixed conditioning profile only if the already known conditioning-sensitive case still needs mechanism localization. Use the saved prompt pair and collect the interaction at the injection block, a later residual, and clean. The `conditioning_fixed` profile captures blocks 5 and 12 and budgets six auxiliary calls, including up to two reference calls. Use recomputed mode only when the question is whether the intervention algorithm itself changes with C1.
4. Use the sign-even or low-band active profile only after steps 2–3 identify a component worth testing. Compare the decoded planner output with the native planner and inspect `selected_candidate` and `applied_clean_displacement_rms`. Use the corresponding norm-matched control only when necessary to test specificity.
5. If half-amplitude results are unstable or near the repeat floor, change one execution factor on the same frozen export and compare paired site profiles. Keep the distinction between native dtype, dequantized approximation, original weights and a different model.


## Conditioning contrast (directional research)

Select `conditioning_contrast`, sites `clean`, band `all`, and connect a second global CONDITIONING. The primary condition C0 is the complete prompt; C1 is a controlled ablation of one explicit requirement. Keep the actual solver state, weights, reference latents and other settings fixed. This experiment measures the conditional prediction contrast, not a feature-intervention factorial.

For native clean predictions D0 and D1 at the same noisy state, the contrast is D0 - D1. The `contrast` component extrapolates toward C0, `contrast_reverse` uses its opposite, and `contrast_spatial` circularly shifts the contrast by half the latent height and width. The spatial control preserves the pre-rounding norm and Fourier magnitude but may retain global and correlated signal; it is not an independent direction. `observe` leaves the sampler unmodified. The existing candidate gain, target RMS, native-rounded trust limit and optional external score acceptance apply. A target is rejected if it cannot be reached within the configured gain. A quality metric is not inferred from contrast magnitude.

This mode requires a single live positive CFG-1 dispatch, native feature and initialization paths disabled, no frozen-state replay, no projection study, and no band or cell selection. It reuses the live baseline and spends one additional DiT evaluation per selected state (two with repeat baseline enabled). The alternate uses the same native-conditioning conversion and reference checks as the factorial experiments. No feature reference or spectral capture is performed. It is a selective conditional-contrast guidance experiment, not a zero-forward method.

The export contains baseline_clean, D10_clean, contrast_native_delta, frozen_native_input, and when available candidate_clean and applied_clean. The clean tensors are in ComfyUI VAE coordinates; contrast_native_delta is in native diffusion coordinates. The manifest includes C0/C1 fingerprints, direction norm and cosine, control shift and actual applied RMS. Compare candidate and final images separately. Before using a predicted-clean proxy to choose edits, demonstrate that its ranking predicts final-image improvement on independent cases. Report declines and regressions. Do not use the existing confirmation split to tune the intervention.
